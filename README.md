# Frame Forge

Frame Forge — приложение для улучшения видео на Windows с помощью GPU. Оно может обрабатывать как отдельные видеофайлы, так и серии из библиотеки AnimeLib Desktop.

## Установка

- Windows x64 и видеокарта с поддержкой Vulkan.
- [Video2X 6.4.0 для Windows](https://github.com/k4yt3x/video2x/releases/tag/6.4.0) и [FFmpeg с ffprobe](https://www.gyan.dev/ffmpeg/builds/) для обработки видео.

1. Запустите `FrameForge-Setup.exe`. Установщик добавит Frame Forge в меню «Пуск» для текущего пользователя и предложит создать ярлык на рабочем столе.
2. Распакуйте Video2X и FFmpeg с ffprobe в подпапку `tools/` рядом с установленным `FrameForge.exe`. Приложение найдёт их автоматически. Сохраните структуру папок Video2X с DLL и весами моделей.

Среда .NET включена в установщик. Приложение можно удалить через параметры Windows.

Проверено на NVIDIA GeForce RTX 5080. Приложение использует устройство Vulkan с индексом `0`. Список устройств выводит команда `video2x --list-devices`.

## Разработка

- Windows x64.
- .NET 10 SDK. Для работы с решением можно использовать Rider.
- Видеокарта с поддержкой Vulkan, Video2X и FFmpeg с ffprobe нужны для запуска обработки видео и сквозного GPU-теста.

Для локальной обработки распакуйте инструменты в `tools/` в корне репозитория. Откройте `frame-forge.sln` в Rider или выполните из корня репозитория:

```powershell
dotnet build frame-forge.sln -c Release
dotnet run --project src/FrameForge -c Release --no-build
```

### Сборка установщика

Установите [Inno Setup 6](https://jrsoftware.org/inno-setup/downloads) и выполните из корня проекта в Windows PowerShell 5.1 или PowerShell 7:

```powershell
./installer/Build-Installer.ps1
```

Если компилятор находится в нестандартной папке, передайте путь к `ISCC.exe` через `-Compiler`. Скрипт публикует автономную сборку Windows x64 и создаёт `artifacts/installer/FrameForge-Setup.exe`.

## Обработка видео

1. Выберите алгоритм, папку результатов и разрешение. Доступны 1080p, 1440p, 4K и свой размер. Кадр вписывается в заданные границы с сохранением пропорций.
2. Для короткой пробы снимите флажок **«Обрабатывать видео целиком»** и укажите начало и длину фрагмента в секундах. Максимальная длина пробы — 300 секунд.
3. Нажмите **«Добавить видео…»** и выберите файлы. Параметры фиксируются при добавлении каждого задания.
4. Нажмите **«Запустить очередь»**. Файлы обрабатываются по одному. Остановка отменяет текущую обработку, ожидающие задания сохраняются. Прерванное задание можно запустить заново с начала.

Для обычных файлов оригинал остаётся на месте. В папке задания сохраняются `enhanced.mkv`, `processing.log` и `report.json`. По умолчанию результаты идут в папку **Видео → Frame Forge**, а очередь и настройки хранятся в `%LOCALAPPDATA%\FrameForge\workspace.json`.

| Профиль | Когда использовать |
| --- | --- |
| Real-CUGAN SE без шумоподавления | Высокое качество для аниме с чистым исходником |
| Real-CUGAN SE с очисткой | Аниме с шумом или артефактами сжатия, внутренний масштаб 2× |
| Real-ESRGAN Video v3 | Базовый профиль для аниме |
| Real-ESRGAN Plus | Обычное видео, внутренний масштаб 4× |
| Real-CUGAN Pro | Консервативный профиль для аниме, внутренний масштаб 2× или 3× |

Если модель выдаёт кадр больше целевого, FFmpeg уменьшает его через Lanczos. Промежуточное видео без потерь может занимать много места. Итоговое видео кодируется в H.264. В настройке «Качество кодирования H.264» доступны CRF 22 (по умолчанию), 20 и 16. Выбранный CRF применяется к новым заданиям. Кодирование выполняется на CPU, модель работает на GPU.

## Интеграция с AnimeLib Desktop

В Frame Forge нажмите **«Из AnimeLib…»** и выберите скачанные серии. Путь к каталогу можно задать в разделе **«Библиотека AnimeLib»**. Для серии включите обработку целого видео и закройте AnimeLib перед запуском очереди.

Frame Forge подготавливает совместимый MP4, проверяет его и заменяет файл серии. Временный оригинал удаляется после успешной проверки замены. Если проверка или завершение замены после создания копии не удастся, временный оригинал сохраняется.

В сборке AnimeLib с поддержкой Frame Forge серия отображается с фактическим разрешением и меткой `(FF)`, например **1440p (FF)**. Управление обработкой находится в Frame Forge. Импорт серий, сохранённых как локальные HLS-плейлисты, пока не поддерживается.

## Разработка и тесты

| Проект | Назначение |
| --- | --- |
| `src/FrameForge` | Интерфейс WPF |
| `src/FrameForge.Core` | Обработка видео, очередь, хранилище и интеграция с AnimeLib |
| `tests/FrameForge.Tests` | Тесты xUnit |
| `tests/FrameForge.Smoke` | Сквозные проверки с Video2X и FFmpeg |

Обычный запуск тестов не требует GPU:

```powershell
dotnet test frame-forge.sln -c Release
```

Чтобы включить тест с реальными инструментами и измерить покрытие ядра, выполните из корня проекта:

```powershell
$env:FRAMEFORGE_TEST_ROOT = (Get-Location).Path
dotnet test frame-forge.sln -c Release --settings coverage.runsettings --collect 'XPlat Code Coverage' --results-directory experiments/test-results
```

Сквозной тест создаёт синтетическое видео и временный каталог AnimeLib в `experiments/`. Отчёт Cobertura содержит покрытие строк и ветвей `FrameForge.Core`. Целевое покрытие — 80%.

Если Video2X 6.4.0 завершится с ошибкой `0xC0000005` после сообщения об успешной обработке, Frame Forge проверит готовый файл и отметит задание предупреждением, если проверка пройдёт. При сбое откройте журнал задания и `report.json`, если он успел сохраниться.
